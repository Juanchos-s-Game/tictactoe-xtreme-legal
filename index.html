Política de privacidad de TicTacToe Xtreme

Última actualización: 24 de septiembre de 2026. Responsable: Juancho's Game. Contacto: tictactoe082026@gmail.com.

Datos guardados en el dispositivo

Al crear una cuenta local, la aplicación solicita nombre, apellido, correo electrónico, edad, contraseña y clave de recuperación. Guarda los datos de la cuenta en el dispositivo. La contraseña y la clave de recuperación se guardan como valores derivados mediante hash y sal; no se guardan como texto legible en la base de datos.

La aplicación guarda localmente estadísticas de partidas, preferencias, configuraciones, temas personalizados y archivos que el usuario incorpora para personalizar el juego. El correo sirve para identificar la cuenta local y separar sus datos de los de otras cuentas del mismo dispositivo. La cuenta no es una cuenta de Google Play y no se sincroniza entre dispositivos.

Uso y transferencia

Estos datos permiten iniciar sesión, recuperar la contraseña, conservar estadísticas y aplicar personalizaciones. En la versión descrita aquí, la aplicación no envía los datos de las cuentas locales a un servidor del desarrollador ni incluye publicidad o compras dentro de la aplicación. Los archivos externos elegidos por el usuario se emplean para personalizar su dispositivo; el usuario debe contar con los derechos necesarios sobre ellos.

Almacenamiento y seguridad

Los datos de las cuentas y las estadísticas se guardan en el espacio local de la aplicación. El respaldo automático de los datos de la aplicación está desactivado en la configuración de Android de esta versión. La seguridad del dispositivo también depende de las protecciones que el propio usuario tenga activadas.

Eliminación de cuenta y datos

Para borrar una cuenta desde la aplicación, inicia sesión y abre Configuración → Administración → Eliminar cuenta. Confirma la operación. Se eliminan la cuenta local y sus datos asociados en ese dispositivo, incluidas sus estadísticas, configuración, temas y archivos personalizados que la aplicación haya copiado a su almacenamiento. Los archivos originales ubicados fuera de la aplicación no se eliminan. Esta operación es irreversible.

También puedes solicitar instrucciones de eliminación desde fuera de la aplicación escribiendo a tictactoe082026@gmail.com. Como el desarrollador no conserva una copia remota de las cuentas locales, no puede borrar directamente los datos almacenados en tu teléfono. Si ya desinstalaste el juego y no conservas sus datos, no hay una cuenta remota pendiente de eliminar. Si tienes varios dispositivos, elimina los datos locales en cada uno.

Cambios

Si futuras versiones incorporan anuncios, compras o servicios externos, esta política se actualizará para describir sus prácticas antes de publicar esa versión.
